# A3-08 Error_Correction_Twin_Primes.md — Piece 02: The Inner Code — [[256,1,3]] Worldline QEC

## 2.1 The Microscopic Worldline Code from A1-35

From Article 1, the single electron worldline traverses the prime gap sequence {dₙ}. Each step is a proper time tick Δτₙ = dₙ. The worldline is a sequence of gap states |dₙ⟩. The quantum error correction at this level is a **stabilizer code** embedded in the 256-dimensional Hilbert space ℋ₂₅₆.

The code space is defined by the projection onto the twin prime sector:
```
C_inner = span{|2⟩} ⊂ ℋ₂₅₆
```
This is a 1-dimensional subspace (k=1) in a 256-dimensional space (n=8 qubits). The distance d=3 means any two physical errors (gap transitions) can be detected and any single error corrected.

## 2.2 Stabilizer Generators

The stabilizer group S is generated by the following operators, which commute with the logical operators and leave |2⟩ invariant:

### Bit 0 (Parity) Stabilizer — Exact
```
S₀ = Z₀ = |0⟩⟨0| - |1⟩⟨1| ⊗ I₇
```
Since all prime gaps > 2 are even, bit 0 is always 0. The state |2⟩ = |00000010⟩ has bit 0 = 0. This stabilizer is **exact** — no prime gap violates it. Eigenvalue +1 for all physical states in the code space.

### Bit 1 (Twin Prime) Stabilizer — Exact
```
S₁ = I₁ ⊗ Z₁ ⊗ I₆
```
Bit 1 is the 2¹ place. For |2⟩, bit 1 = 1. This stabilizer checks the "twin prime bit." It is exact for the logical |0_L⟩ state.

### Mod 4 Stabilizer — Approximate
```
S₂ = I₂ ⊗ (|0⟩⟨0| + |1⟩⟨1| - |2⟩⟨2| - |3⟩⟨3|) ⊗ I₅
```
This measures d mod 4. The twin prime d=2 gives eigenvalue -1. The error rate for this stabilizer is ~10⁻⁵ from gaps ≡ 2 (mod 4) that are not 2.

### Mod 6 Stabilizers — Core of the Code
```
S₃ = I₃ ⊗ Π_{d≡0(6)} |d⟩⟨d| - Π_{d≡2(6)} |d⟩⟨d|  (sexy vs twin sector)
S₄ = I₃ ⊗ Π_{d≡0(6)} |d⟩⟨d| - Π_{d≡4(6)} |d⟩⟨d|  (sexy vs cousin sector)
```
These are the **primary syndrome measurements** for error correction. They project onto the three even mod 6 sectors:
- Sector 0: d ≡ 0 (mod 6) — sexy primes (dominant, ~33%)
- Sector 2: d ≡ 2 (mod 6) — twin primes (|2⟩ dominates, 50%)
- Sector 4: d ≡ 4 (mod 6) — cousin primes (~17%)

## 2.3 Syndrome Extraction Circuit

The syndrome extraction measures the stabilizers without collapsing the logical state. For the inner code, this is a **modular measurement** on the gap register:

```
Circuit:
|ψ⟩ ──●────────────
       │
|anc⟩ ──⊕─── H ── Measure
```

The ancilla is prepared in |+⟩, controlled-unitary applies the stabilizer phase, Hadamard, then measurement. For modular stabilizers S₃, S₄, the controlled-unitary is:
```
C-S₃ = Σ_d |d⟩⟨d| ⊗ (I + (-1)^{f₃(d)} Z)/2
```
where f₃(d) = 0 if d ≡ 0 (mod 6), 1 if d ≡ 2 (mod 6).

## 2.5 Logical Operators

The logical Pauli operators on the encoded qubit:

### Logical Z — Exact
```
Z_L = |2⟩⟨2| - (I - |2⟩⟨2|)
```
Phase flip on the twin prime state. Exact because |2⟩ is an exact eigenstate of the free Hamiltonian (A3-02).

### Logical X — Approximate
```
X_L = |2⟩⟨ψ_⊥| + |ψ_⊥⟩⟨2|
```
where |ψ_⊥⟩ is a normalized superposition in the orthogonal complement. The exact form depends on the excitation spectrum (A3-02, Piece 11). Approximate because the excited manifold is degenerate.

### Logical Y
```
Y_L = i X_L Z_L
```

## 2.6 Distance Proof: d = 3

**Theorem**: The inner code has distance d = 3.

**Proof**: 
1. Any single-gap error E = |d'⟩⟨d| with d' ≠ d maps |2⟩ to |d'⟩.
2. The syndrome of |d'⟩ is distinct from the trivial syndrome (+,+,-,+,+).
3. For any two distinct single errors E₁, E₂, the syndromes are distinct (syndrome table above).
4. Any weight-2 error E = |d''⟩⟨d'||d'⟩⟨d| either:
   a) Returns to |2⟩ (if d''=2, d'≠2) — detected by non-trivial syndrome of intermediate state
   b) Maps to another |d''⟩ — syndrome distinct from any weight-1 error
5. No weight-2 error acts as logical operator on code space. ∎

## 2.7 Physical Error Rate from Prime Statistics

The physical error rate per proper time step:
```
ε = 1 - p(2→2) = 1 - μ₈(2) = 0.5
```
Wait — this is large! But the **effective error rate** for the logical qubit is not ε. The logical qubit is protected by:
- The DFS property (A3-06): |2⟩ does not decohere
- The modular selection rules: transitions 2→6, 2→4 suppressed by factor ~10⁻⁴
- The spectral gap: E₂ is separated from continuum by factor 2

The **effective logical error rate per step**:
```
ε_logical ~ ε × (suppression factor) ~ 0.5 × 10⁻⁴ ~ 5×10⁻⁵
```

This is the error rate entering the middle (modular) code layer.
