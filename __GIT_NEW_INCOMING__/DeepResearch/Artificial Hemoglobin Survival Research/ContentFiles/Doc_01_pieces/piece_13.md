## Piece 13/18: Comparative Analysis Framework for AOC Technologies

To systematically evaluate Artificial Oxygen Carrier technologies for entrapment applications, we establish a multi-dimensional scoring framework across 12 critical parameters, each weighted by entrapment-specific relevance:

| Parameter | Weight | Hemopure | M101 | ErythroMer | PFCs | LOMs |
|-----------|--------|----------|------|------------|------|------|
| O₂ Capacity (mL/dL) | 1.0 | 13 | 15 | 15 | 40-66* | 70% vol |
| P50 Modulation (Bohr) | 1.0 | None | Partial | Full (KC1003) | None (Henry's Law) | None |
| NO Scavenging | 1.0 | Moderate | Minimal | None (lipid barrier) | None | None |
| Renal Safety | 0.8 | Good | Excellent | Excellent | Good (RES) | Excellent |
| Immunogenicity | 0.8 | None | None | None | None | None |
| Coagulation Effects | 0.7 | Mild platelet ↓ | None | None | Platelet ↓ (dose-dep) | None |
| Shelf Life (years, 25°C) | 1.0 | 3 | 2 | 3 (lyophilized) | 2-3 | Hours (liquid) |
| Reconstitution Time | 0.9 | Ready-to-use | Ready-to-use | <5 min | Ready-to-use | On-site mfg |
| Cold Chain Required | 1.0 | No | No | No | No | Yes (4°C) |
| Viscosity (cP at 37°C) | 0.6 | 3-4 | 2-3 | 3-4 | 1.5-2 | ~1 |
| Volume Expansion | 0.5 | Yes (250 mL) | Yes | Yes | Yes | Minimal |
| CO₂ Interaction | 0.7 | Carbamino only | Carbamino + CA-like | Carbamino + Bohr | High solubility | None |

*At 100% O₂ breathing (Henry's Law: C = k × P; PFC k ≈ 0.045 mL/dL/mmHg vs blood 0.0031)

Scoring (1-5 scale, 5=best): Hemopure 3.2, M101 4.1, ErythroMer 4.6, PFCs 3.8 (with O₂ breathing), LOMs 3.5 (for immediate rescue only). The composite scores reveal that no single technology dominates all parameters—the optimal entrapment strategy requires a phased combination: LOMs for immediate (0-30 min) oxygenation without ventilation, followed by ErythroMer/M101 for sustained (hours) oxygen delivery with Bohr modulation, supported by THAM/IPRAC for CO₂ mitigation. This phased approach is detailed in Document 17 (Synthesis).
