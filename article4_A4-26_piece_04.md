# Scattering Amplitudes: Adelic Veneziano Formula

## 4.1 Adelic Beta Function

The 4-point open string amplitude generalizes to:
```
A(s,t) = g_s² ∫_A |x|_A^{α's} |1-x|_A^{α't} dμ_A(x)
```
where the adelic integral factorizes:
```
A(s,t) = B(-α's-1, -α't-1) × ∏ₚ Bₚ(-α's-1, -α't-1)
```
with p-adic beta functions Bₚ.

## 4.2 Prime-Regge Trajectories

The poles of the adelic amplitude give Regge trajectories:
```
α(s) = α(0) + α's + Σₚ cₚ log(1 + s/p²)
```
The prime sum provides the correct asymptotic density of states ρ(m) ~ exp(2π√(m/π)).

## 4.3 Crossing Symmetry and Prime Duality

Adelic crossing symmetry A(s,t) = A(t,u) = A(u,s) holds due to the functional equation of the adelic zeta function. This is the string-theoretic origin of prime duality in A4-25.
