### Key Upgrades Over Study Version

#### 1. Glass Test Tube / Droplet World (User choice: YES)
- `biome_engine.js` draws a **visible glass ellipse** on the canvas each frame:
  - Outer glow: `rgba(56,189,248,0.12)` radial gradient
  - Glass rim: `rgba(56,189,248,0.3)` 2px stroke along the ellipse
  - Subtle refraction shimmer: 3-point arc segments slightly brighter at random positions
- Physics boundary in `physics.js`:
  ```javascript
  function glassBoundary(c, rx, ry, cx, cy) {
    const nx = (c.x - cx) / rx;
    const ny = (c.y - cy) / ry;
    if (nx*nx + ny*ny >= 1) {
      // reflect velocity across ellipse normal
      const dot = c.vx*nx + c.vy*ny;
      c.vx -= 2 * dot * nx;
      c.vy -= 2 * dot * ny;
      // push back inside
      const scale = 0.98 / Math.sqrt(nx*nx + ny*ny);
      c.x = cx + nx * rx * scale;
      c.y = cy + ny * ry * scale;
    }
  }
  ```
- World is no longer wrapping — `wrapBoundary()` replaced by `glassBoundary()` for all species except `photon`/`neutrino`/`graviton` which still streak across

#### 2. Living Bubbles — Physics Coupled (User choice: YES)
- New `BubbleSystem` class inside `biome_engine.js`:
  - Reads positions of all `.bubble` DOM elements via `getBoundingClientRect()` per frame (capped at 30 tracked bubbles for perf)
  - Converts screen positions → world coords
  - Tracks each bubble's estimated Y velocity (from CSS `moveUp` animation progress)
- **Buoyancy drift field**: each bubble contributes an upward force `{vx:0, vy:-25}` to creatures within 60 world-units (falls off with distance)
- **Boarding**: when a light/fast creature (photon, pion, kaon species) is within 15 world-units of a bubble:
  - `creature._boardedBubble = bubble` — creature velocity matches the bubble's rise
  - Creature renders slightly offset on bubble's edge (visual riders)
- **Burst**: when 3+ creatures board the same bubble:
  - DOM bubble element: `bubble.style.opacity = '0'` (fade-out)
  - Riders: scatter with velocity kick `{vx: random×60, vy: random×60}`
  - Spark visual at burst position
  - After 8s, bubble element returns to normal opacity
- **Net effect**: watching creatures hitch rides upward, cluster, burst, and scatter down feels genuinely alive

#### 3. Enhanced Convection Flow Field
- `curlNoise()` gains a `convection` overlay term:
  ```javascript
  // Warm bottom, cool top → natural convection loop in a test tube
  const convY = -((cy - y) / worldH) * 12;  // stronger upward force at bottom
  const convX = Math.sin((x / worldW) * Math.PI) * 5; // slight circular return flow
  ```
- Result: at the bottom of the tube, the fluid pushes upward (heated); at the top it cools and flows back down the sides. Creatures naturally circulate.

#### 4. POV Microscope Eyepiece Vignette
- In `pov_camera.js`, during POV mode, `drawPovOverlay()` renders:
  - Circular black mask (everything outside a centered circle is darkened)
  - Chromatic aberration rings at the edge (thin cyan ring inside, thin red ring outside)
  - Cross-hair markings at screen centre (faint, like a real microscope reticle)
  - Corner information overlay: magnification "40× → 320×" (scales with zoom)

#### 5. HUD: Tube Environment Panel
- New HUD section (within right panel): "TUBE ENVIRONMENT"
  - `pH`: displays `7.4` ± small drift (randomised if G-toggle active)
  - `Temp °C`: displays `37` ± small drift
  - `Bubble Count`: live count of boarding bubbles
  - `Convection`: UP ↑ / DOWN ↓ / SWIRL ↻ indicator based on dominant flow direction
