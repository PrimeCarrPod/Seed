## 1. FQXi ZENITH GRANTS

### Submission System
- **Platform:** FQXi website (fqxi.org/programs/zenith-grants/)
- **Process:** Two-stage: Initial Proposal (LOI) → Full Proposal if invited
- **Account:** Create FQXi account, submit via online form

### Format Requirements
- **Initial Proposal:** Online form fields + document uploads
- **Full Proposal (if invited):** Detailed narrative, budget, biosketches
- **Font/Spacing:** Standard readable format (no strict font size specified)
- **Page Limits:** Not strictly specified for initial; full proposal typically 10-15 pages

### Attachment Policy
- **Allowed:** PDF uploads for proposal narrative, biosketches, budget justification
- **Size Limits:** Not explicitly stated; keep under 10MB each
- **Required Attachments:** 
  - Proposal narrative
  - PI biosketch (2-3 pages)
  - Budget justification
  - Current & pending support (if applicable)

### Key Dates
- **Next Round:** TBD (sign up for mailing list at fqxi.org)
- **Review Cycle:** Expert peer review, similar to NSF
- **Notification:** After screening, invited to full proposal

### Special Notes
- **Non-profit requirement:** Funds only to non-profit orgs or equivalent
- **Independent researchers:** Must partner with eligible institution
- **Unconventional focus:** Research unlikely to be funded by NSF/DOE
- **No self-nominations:** Must be proposed by PI

## 2. NSF EPP-T (ELEMENTARY PARTICLE PHYSICS - THEORY)

### Submission System
- **Platform:** Research.gov (primary) or Grants.gov
- **Account:** NSF ID + Organization registration in Research.gov
- **SAM/UEI:** Active SAM registration + valid UEI required (90+ days advance)

### Format Requirements (PAPPG 24-1)
| Section | Page Limit | Notes |
|---------|------------|-------|
| Project Summary | 1 page | Overview, Intellectual Merit, Broader Impacts |
| Project Description | 15 pages | Core technical content |
| References Cited | No limit | Bibliographic only |
| Biographical Sketch | 2 pages each | SciENcv/NSF format |
| Current & Pending Support | No limit | Each senior person |
| Collaborators & Affiliations | No limit | Each senior person |
| Synergistic Activities | 1 page each | Up to 5 examples |
| Budget & Justification | 5 pages | Per year, detailed |
| Facilities/Equipment | No limit | Internal/external resources |
| Data Management Plan | 2 pages | Required |
| Mentoring Plan | 1 page | If grad students/postdocs |

### Font/Spacing/Margins
- **Font:** Standard (Times New Roman, Computer Modern, etc.)
- **Size:** ≥10 point
- **Spacing:** Single-spaced
- **Margins:** ≥1 inch all sides
- **Pagination:** Sequential, bottom center

### Attachment Policy
- **Format:** PDF only (Research.gov converts)
- **Naming:** Follow Research.gov conventions
- **Single-Copy Docs:** Auth to deviate, suggested reviewers, proprietary info, certifications
- **Compliance Checks:** Automatic pre-submission validation

### Key Dates
- **Target Date:** 4th Tuesday in January annually
- **FY2027:** January 26, 2027
- **Late submissions:** Considered for next fiscal year

### Special Requirements
- **Co-PI Required:** University-affiliated physicist (NSF eligibility)
- **New PI Consultation:** Strongly encouraged to contact program officer
- **Program Officer:** Keith R. Dienes (EPP-T@nsf.gov, 703-292-5314)

## 4. SIMONS COLLABORATION IN MPS

### Submission System
- **Platform:** Simons Award Manager (SAM) — https://sam.simonsfoundation.org/
- **Account:** Create SAM account, start application under own account
- **Institution:** Must have SAM institutional profile (coordinate with grants office)

### LOI Format (Due Oct 29, 2026, 12pm ET)
| Component | Limit | Format |
|-----------|-------|--------|
| LOI Narrative | 3 pages + 1 page refs/figs | PDF, single-spaced, ≥10pt, ≥0.5" margins |
| Biosketches | 2-3 pages each | SciENcv/NIH/NSF format or CV |
| Naming | LastName_FirstName_Biosketch.pdf | |

### Full Proposal (Invitation Only, Due Feb 25, 2027, 12pm ET)
| Component | Limit | Format |
|-----------|-------|--------|
| Proposal Narrative | 12 pages + 2 pages refs/figs | PDF, same formatting |
| Biosketches (all PIs/co-Is) | 2-3 pages each | Same naming convention |
| Budget | 4-year | SAM budget tab |
| Publications | ≤10 each PI/co-I | LastName_FirstName_Publications.pdf |
| Current/Pending Support | Per person | LastName_FirstName_Support.pdf |

### Eligibility
- **Director:** Tenured faculty (or equiv) at US/Canadian institution with PhD program
- **PIs/co-Is:** Tenured/tenure-track at educational institution
- **No co-PI role:** Simons uses "Additional PI" and "co-Investigator"

### Attachment Policy
- **All uploads:** PDF via SAM
- **Font:** Single-spaced, ≥10pt, ≥0.5" margins
- **AI Disclosure:** Required (extent of generative AI use)
- **Sign-off:** Institutional signing official required for full proposal

## 5. SIMONS TARGETED RESEARCH GROUPS

### Submission System
- **Platform:** Simons Award Manager (SAM) — same as above
- **Deadline:** Rolling (anytime)
- **Decision:** Within 3 months of LOI

### LOI Format
| Component | Limit | Format |
|-----------|-------|--------|
| LOI Narrative | 2 pages + 1 page refs/figs | PDF, signed by main PI on letterhead |
| Budget | 1 page | Tentative yearly budget |
| Biosketches | 2-3 pages each | SciENcv/NIH/NSF format or CV |
| Naming | LastName_FirstName_Biosketch.pdf | |

### Full Proposal (If Invited)
| Component | Limit | Format |
|-----------|-------|--------|
| Proposal Narrative | 6 pages + 2 pages refs/figs | PDF |
| Biosketches | 2-3 pages each | Same |
| Budget | Up to 5 years | SAM budget tab |
| Publications | ≤10 each | LastName_FirstName_Publications.pdf |
| Current/Pending Support | Per person | LastName_FirstName_Support.pdf |

### Special Notes
- **Institutional sign-off:** NOT required for LOI stage
- **Required for full proposal:** Signing official signature
- **Subcontracts:** All but one budget as subcontract if multi-institution
- **Rolling review:** Decisions within 3 months

## 6. BREAKTHROUGH PRIZE IN FUNDAMENTAL PHYSICS

### Submission System
- **Platform:** Online nominations form at breakthroughprize.org/Nominations
- **Period:** April 22, 2026 – July 17, 2026 (for 2027 prizes)
- **Self-nomination:** PROHIBITED

### Nomination Requirements
| Component | Requirement |
|-----------|-------------|
| Nominee info | Biographical details |
| Nominator info | Biographical details |
| Letter of Recommendation | At least 1 third-party letter |
| Citations | 1-10 from academic database (e.g., INSPIRE, arXiv) |
| Achievement | "Profound contributions to human knowledge" |

### Attachment Policy
- **Online form:** Text fields + file uploads
- **Citations:** Upload or link from specified database
- **Letter:** PDF upload
- **No strict page limits** but concise preferred

### Key Notes
- **Prize:** $3M (can be shared)
- **New Horizons:** $100K for early-career (≤12 yrs post-PhD)
- **Vera Rubin Prize:** $50K for women physicists (≤2 yrs post-PhD)
- **Selection Committee:** Includes Arkani-Hamed, Maldacena, Witten, etc.

## 7. CLAY MATHEMATICS INSTITUTE

### Submission System
- **Platform:** Email to president@claymath.org (cc admin@claymath.org)
- **Deadline:** October 15 annually
- **Format:** Email with PDF attachments

### Required Materials
| Document | Format |
|----------|--------|
| Letter of Nomination | PDF (signed) |
| Curriculum Vitae | PDF |
| Publication List | PDF |
| References | Names + contact info for 2 references |

### Fellowship vs Research Award
- **Fellowship:** For recent PhDs (≤5 years), employment at CMI
- **Research Award:** For outstanding achievements (annual conference)

### Attachment Policy
- **All PDFs** via email
- **No online portal** — direct email submission
- **File naming:** Clear, professional (LastName_FirstName_DocType.pdf)
