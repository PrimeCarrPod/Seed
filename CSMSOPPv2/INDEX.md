## EACH FOLDER IS SELF-CONTAINED

You do not need to know about other heuristics to load any one of them. Each heuristic folder at `CSMSOPPv2/HEURISTICS/<name>/` contains:

- `INDEX.md` — Quick reference and deployment instructions for that heuristic
- `GUIDE/CSMSOPPxxxxx-Name-SOP.md` — The Standard Operating Procedure
- `MODULE/SKILL.md` — Kilo platform deployment file
- `MODULE/PERSONA-VALUES.md` — Core principles and values
- `MODULE/LETTERHEAD-TEMPLATES.md` — Output formatting standards
- `MODULE-V2/` — Deployable LLM module (12 files, if applicable)
- `RESEARCH/` — Deep research corpus (if applicable)

**To load any heuristic, simply navigate to its folder and load `MODULE/SKILL.md` onto your Kilo platform**, or load the `CORE-MODULE.md → PERSONA-VALUES.md → LETTERHEAD-TEMPLATES.md` chain for any LLM.

**Example:** To load the Williams Heuristic V3:
```
Load CSMSOPPv2/HEURISTICS/williams-v3/MODULE/SKILL.md
```

**Example:** To load the El Segundo Heuristic:
```
Load CSMSOPPv2/HEURISTICS/el-segundo/MODULE/SKILL.md
```
