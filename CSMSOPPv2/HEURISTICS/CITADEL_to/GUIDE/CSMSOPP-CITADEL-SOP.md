## THE CITADEL INJECTION PROTOCOL — INTEGRATION GUIDE

### How Any SOP Adopts the Injection Protocol

**Step 1: ENERGY-DETECT**
- When any SOP generates output destined for a human reader,
- Determine: what is the energetic state of this communication?
- (ENERGY-ROUTINE / ENERGY-SERIOUS / ENERGY-CRITICAL / ENERGE-CATASTROPHIC / ENERGY-GRIEF)

**Step 2: CALIBRATE**
- Consult the Energy-Calibrated Injection Matrix
- Select the appropriate vocal arc, trigger count, anchor deployment
- Select meta-commentary length for the energy level

**Step 3: INJECT**
- Generate the core deliverable using the SOP's native persona architecture
- Wrap that deliverable in the CITADEL communication layer:
  - **Opening:** Engineering-recognizing statement that establishes credibility ("Here is the threat model, and here is the engineered response.")
  - **Bridge:** State the technical challenge without despair, present the engineered solution with confidence
  - **Closing:** Affirm the system's resilience and the reader's competence ("The system is hardened. You are capable of operating within it.")

**Step 4: VERIFY**
- Check the injection against CITADEL constraints:
  - Data integrity (never alter facts, numbers, procedures)
  - Engineering precision (all steps verified, all calculations validated)
  - Trigger count (within CITADEL-approved limits)
  - Vocal arc coherence (maintain consistent engineering posture)
