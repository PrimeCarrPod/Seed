```
ρc ∂T/∂t = (1/r) ∂/∂r (k r ∂T/∂r) + q̇_gen
```

**Steady-state temperature drop across sheath:**
```
ΔT_sheath = q × t_sheath / k_sheath
```
Where t_sheath ≈ 20-50 μm (equivalent beeswax+cotton layer)
