## 8. Additional Formulas

### 8.1 Hoop Stress and Buckling
**Hoop Stress (Thin-Walled):**
```
$\sigma_h = \frac{p r}{t}$
```
```
$\sigma_a = \frac{p r}{2t}$
```
```
$p_{cr} = \frac{2E}{\sqrt{3(1-\nu^2)}} \left(\frac{t}{r}\right)^2$
```



### 8.2 Deployment Kinematics
**Deployment Angle:**
```
$\theta(t) = \theta_{\max} \left(1 - e^{-t/\tau}\right)$
```
```
$v_{\text{deploy}} = r \frac{d\theta}{dt} = \frac{r \theta_{\max}}{\tau} e^{-t/\tau}$
```



### 8.3 Tape Suspension System
**Tape Tension:**
```
$T_{\text{tape}} = \frac{W_{\text{hoop}}}{N_{\text{tapes}} \sin(\alpha)}$
```
```
$\delta_{\text{tape}} = \frac{T_{\text{tape}} L}{E A_{\text{tape}}}$
```



### 8.4 Structural Analysis
**Bending Moment:**
```
$M = \frac{p r^2}{2}$
```
```
$\sigma_{\text{bend}} = \frac{M c}{I} = \frac{p r^2 t}{4 I}$
```



### 8.5 Historical Proportion Scaling (Garsault)
**Proportional Scaling:**
```
$D_{\text{hoop}} = k \cdot C_{\text{waist}}$  where $k \approx 1.5-2.0$
```
```
$N_{\text{hoops}} = \left\lceil \frac{H_{\text{skirt}}}{h_{\text{hoop}}} \right\rceil$
```
