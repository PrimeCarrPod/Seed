ω_n = √(K/M) ≈ 5-10 Hz (well above step freq)
```

### 6.4 Fatigue Life Analysis
**Stress Range per Cycle:**
```
Δσ = σ_max - σ_min (from walking motion)
Δσ ≈ 50-100 MPa (depending on edition)
```

**S-N Curve (Spring Steel):**
```
N_f = C × (Δσ)^(-m)
m ≈ 3-5, C ≈ 10¹²-10¹⁵
Target: N_f > 10⁶ cycles
