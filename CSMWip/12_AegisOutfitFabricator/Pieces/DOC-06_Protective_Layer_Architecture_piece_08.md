**Effective Thermal Conductivity (Maxwell-Eucken):**
```
k_eff = k_m × (k_d + 2k_m - 2φ(k_m - k_d)) / (k_d + 2k_m + φ(k_m - k_d))
k_m = 0.026 W/m·K (air), k_d = 0.010 W/m·K (aerogel), φ = 0.85
k_eff ≈ 0.015 W/m·K  ← TARGET ACHIEVED
```
