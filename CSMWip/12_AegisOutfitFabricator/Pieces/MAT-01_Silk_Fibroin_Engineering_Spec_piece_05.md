**Orthotropic Invariants:**
```
I₁ = tr(C)
I₂ = ½[(tr C)² - tr(C²)]
I₄ = a₀ · C a₀ (warp/fiber direction)

```

**2nd Piola-Kirchhoff Stress:**
```
S = 2 × ∂W/∂C + p × C⁻¹
```

**Cauchy Stress (True Stress):**
```
σ = (1/J) F · S · F^T
```
