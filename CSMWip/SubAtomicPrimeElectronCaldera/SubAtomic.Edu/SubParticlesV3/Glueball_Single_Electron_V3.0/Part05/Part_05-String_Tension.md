## 1. Wilson Loop and Area Law

### 1.1 Wilson Loop Expectation Value

The Wilson loop observable in representation $R$:

$$W_R(C) = \mathcal{P} \exp\left( i g \oint_C dx^\mu A_\mu^a T^a \right)$$

The large separation behavior:

$$\langle W_R(C) \rangle \sim e^{-\sigma_R(A)}$$

where $\sigma_R$ is the string tension depending on the representation.

### 1.2 Linear Potential and Regge Trajectories

The interquark potential:

$$V(r) = \sigma r - \frac{\alpha}{r} + \epsilon$$

leading to Regge trajectories:

$$J = \alpha' M^2 + \alpha_0$$

with slope $\alpha' \approx 0.88 \, \text{GeV}^{-2}$.

## 2. String Theory Interpretation

### 2.1 Nambu-Goto Action

The relativistic string action:

$$S = -\frac{1}{2\pi\alpha'} \int d\tau d\sigma \sqrt{-\det(h_{ab})}$$

where $h_{ab} = G_{\mu\nu} \partial_a X^\mu \partial_b X^\nu$.

### 2.2 Virasoro Constraints

The constraints:

$$T^{++} = T^{--} = 0$$
$$T^{-+} = 0$$

relate the tension to the mass spectrum:

$$M^2 = \frac{4\pi^2}{\alpha'} \left( N_L + N_R - 2 \right)$$

### 3.1 Schwarzschild-like Radius

For a glueball of mass $M$:

$$r_g = \frac{2GM}{c^2}$$
