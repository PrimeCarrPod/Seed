## Abstract

The clique decomposition of the self-intersection graph is parameterized directly by the gap counting function. We derive the precise relationship and show how it encodes the topological structure of the fermion worldline.

## 1. Clique Decomposition

### Theorem 1.1 (Exact Decomposition)
```
Γ = ⊔_{g ∈ 𝔾} K_{π_g(N)}
```
where 𝔾 is the set of all gap values observed up to N.

### Theorem 1.2 (Clique Size Distribution)
The sizes of the cliques are given by the gap multiplicity sequence:
```
|K_{π_g(N)}| = π_g(N)
```

### Theorem 1.3 (Total Edges)
The total number of edges in Γ is:
```
|E(Γ)| = Σ_g C(π_g(N), 2) = Σ_g π_g(N)(π_g(N) − 1)/2
```

## 2. Internal Quantum Numbers

### Theorem 2.1 (Clique as Quantum Number)
Each clique K_m corresponds to an internal quantum number of the fermion. The twin prime clique K_{π₂} is the structural backbone.

### Theorem 2.2 (Generations from Clique Hierarchy)
The hierarchy of clique sizes generates the particle generations:
```
Generation i ↔ i-th largest clique
```
For N ~ 10¹² (electron scale), the top cliques correspond to the Standard Model generations.
