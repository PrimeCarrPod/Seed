## 4.2 Hiperco 50 / Vacodil 50 Specifications (CSM Standard)

| Parameter | **Value** | **Test Method** | **CSM Acceptance** |
|-----------|-----------|-----------------|-------------------|
| **Saturation Flux ($B_s$)** | 2.35-2.42 T | DC hysteresis (IEC 60404-4) | ±0.02 T |
| **Coercivity ($H_c$)** | 80-120 A/m | DC hysteresis | ≤ 150 A/m |
| **Max Permeability ($\mu_{max}$)** | 50,000-70,000 | DC hysteresis | ≥ 40,000 |
| **Saturation Magnetostriction ($\lambda_s$)** | 60-80 ppm | Strain gauge | ≤ 100 ppm |
| **Curie Temperature ($T_c$)** | 980°C | Thermomagnetic | ≥ 950°C |
| **Electrical Resistivity** | 25-30 µΩ·cm | 4-point probe | 20-35 µΩ·cm |
| **Density** | 8.1-8.2 g/cm³ | Archimedes | ±0.1 |
| **Annealing** | 800°C, 4h, H₂/N₂ | Mill cert | Required |
| **Lamination Thickness** | 0.15-0.35 mm | Micrometer | ±0.01 mm |
| **Insulation Coating** | Inorganic (2-5µm) / Organic (10-20µm) | Visual + Thickness | Per spec |
