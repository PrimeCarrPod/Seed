## 8.4 Additional Test Requirements (Per CSM/DOC-08)

| Test | **Applicable Grades** | **Method** | **Acceptance** | **Rationale** |
|------|----------------------|------------|----------------|---------------|
| **Demag Curve (Full B-H Loop)** | All PM grades | IEC 60404-5 / JIS C 2510-1 | Rectangularity > 0.95 | Quality indicator |
| **Thermomagnetic Analysis** | All PM grades | IEC 60404-8-1 Annex B | $T_c$ match grade | Phase purity |
| **Pulse Magnetometry (High Field)** | NdFeB, SmCo | IEC 60404-7 | $H_{cJ}$ at 7-10 MA/m | Saturation verification |
| **Microstructure (SEM/TEM)** | Fe₁₆N₂ (pilot) | ASTM E3 / E986 | α"-phase > 90%, grain < 500nm | Process control |
| **Nitrogen Depth Profile (SIMS)** | Fe₁₆N₂ | ASTM E1653 | 10.8-11.5 at% N, uniform | Phase stability |
| **Lamination Factor (Fe-Co)** | Fe-Co cores | IEC 60404-2 | > 0.95 (0.2mm lam) | Core loss control |
| **Insulation Resistance (Fe-Co)** | Fe-Co laminations | IEC 60404-2 | > 10 MΩ (interlaminar) | Eddy current control |
| **Harmonic Loss (Fe-Co)** | Fe-Co @ 400-2000 Hz | IEC 60404-10 | < 1.5× Steinmetz pred. | High-freq validation |
