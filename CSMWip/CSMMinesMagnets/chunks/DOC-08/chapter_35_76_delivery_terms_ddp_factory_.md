## 7.6 Delivery Terms: DDP Factory, INCOTERMS 2020

### 7.6.1 Standard Terms for CSM Magnetic Mineral Supply

| Term | **DDP (Delivered Duty Paid) — CSM Factory** | Rationale |
|------|---------------------------------------------|-----------|
| **INCOTERMS 2020** | DDP CSM Austin, TX / DDP CSM Stuttgart, DE | Buyer (CSM) takes zero logistics risk |
| **Risk Transfer** | At CSM factory dock (unloaded) | CSM controls receiving QC |
| **Cost Inclusion** | All: mine → port → ocean → import → inland → factory | Single price, no hidden costs |
| **Customs/Duties** | Seller (Aegis-Forge/Tardigradia) responsible | CPTPP/FTA preference claimed by seller |
| **Insurance** | Seller: All-risk + War Risk + Magnetic Degradation | Seller bears transit risk |
| **Temperature Control** | Seller: Reefer + genset + monitoring to factory door | Fe₁₆N₂ cold chain integrity |

### 7.6.2 Pricing Formula (DDP per kg Delivered)

$$\text{DDP Price} = P_{\text{mine}} + C_{\text{sep}} + C_{\text{mag}} + C_{\text{pack}} + C_{\text{port}} + F_{\text{ocean}} + I_{\text{ins}} + D_{\text{duty}} + C_{\text{inland}} + M_{\text{margin}}$$

Where:
- $P_{\text{mine}}$ = Mine gate price (ore/concentrate, $/kg REO)
- $C_{\text{sep}}$ = Aegis-Forge separation cost ($/kg REO)
- $C_{\text{mag}}$ = Magnet manufacturing (sinter, machine, coat, $/kg magnet)
- $C_{\text{pack}}$ = Packaging + shielding ($/package)
- $C_{\text{port}}$ = Port handling, docs, TCMN storage ($/ton)
- $F_{\text{ocean}}$ = Ocean freight ($/kg, route-specific)
- $I_{\text{ins}}$ = Insurance (0.3% CIF + war risk + mag degradation)
- $D_{\text{duty}}$ = Import duty (0% under Chile-US FTA / CPTPP with e-CO)
- $C_{\text{inland}}$ = Port-to-factory rail/truck ($/kg)
- $M_{\text{margin}}$ = Tardigradia/Aegis-Forge margin (15-20%)
