## 9.1 Methodology: Claim-to-Source Mapping per DOC-07

**Traceability Matrix Structure** (adapted from DOC-07 §9.1):

| Field | Description |
|-------|-------------|
| **Claim ID** | Unique identifier: DOC-08-CH#-SEC#-CLM### |
| **Chapter** | Chapter number (1-8) |
| **Section** | Section number |
| **Claim Text** | Exact claim as stated in document |
| **Primary Source** | Document, dataset, regulation, or expert source |
| **Source Type** | Primary (regulation, measured data), Secondary (report, analysis), Tertiary (expert opinion) |
| **Verification Method** | How claim can be independently verified |
| **Confidence** | High (≥2 primary sources), Medium (1 primary + secondary), Low (expert only) |
| **Last Verified** | Date of last source check |
| **Cross-Ref** | Links to DOC-01..07, other chapters |

**Confidence Thresholds for DOC-08**:
- **Port/Rail Infrastructure**: High (official port master plans, concession contracts, rail tariff filings)
- **Shipping Regulations**: High (IMDG Code, IATA DGR, MIL-STD, ASTM — official texts)
- **Customs/Trade**: High (CPTPP treaty text, Chilean law, SICEX publications)
- **Cost Models**: Medium (industry benchmarks, carrier quotes, port tariffs — verified 2024)
- **Resilience Scenarios**: Medium (historical data + modeling assumptions)
- **Community/Indigenous**: High (legal texts, CONADI records, community agreements)
