## 8.9 Social License Maintenance Protocol

Social license is **not a permit — it is a continuous relationship**. This protocol ensures ongoing legitimacy.

### 8.9.1 License Health Metrics (Quarterly Scorecard)

| Metric | Target | Measurement | Frequency | Accountability |
|--------|--------|-------------|-----------|----------------|
| **Trust Index** | ≥ 7.0/10 | Community survey (independent) | Quarterly | FBC/CDC |
| **Grievance Resolution** | 100% < 30 days | Grievance log (blockchain) | Monthly | Community Liaison |
| **Local Procurement** | ≥ 40% by value | Procurement data | Quarterly | CDC |
| **Local Employment** | ≥ 60% host commune | HR data | Monthly | FBC |
| **Indigenous Satisfaction** | ≥ 7.0/10 | Indigenous org survey | Semi-annual | Indigenous Reps |
| **Environmental Compliance** | Zero exceedances | Sentinel + SEA data | Continuous | Environmental Manager |
| **Cultural Protection** | Zero incidents | Chance-find log | Continuous | Cultural Monitor |

### 8.9.2 License Erosion Triggers & Response

| Trigger | Threshold | Automatic Response | Escalation |
|---------|-----------|-------------------|------------|
| **Trust Index** | < 6.0/10 | CEO + FBC/CDC chairs emergency session (7 days) | Independent review |
| **Grievance Backlog** | > 5 unresolved > 30 days | External mediator appointed (14 days) | Arbitration |
| **Env Exceedance** | Any regulatory exceedance | Immediate operational pause, root cause (48 hrs) | Regulatory + Community |
| **Indigenous Withdrawal** | Formal notice from Indigenous org | All operations in territory pause, Consulta restart | Legal + Reputational |
| **Procurement Drop** | < 30% local for 2 quarters | CDC emergency procurement plan (30 days) | Contract renegotiation |

### 8.9.3 Continuous Improvement Cycle

```
QUARTERLY → 1. Data Collection (Sentinels, Surveys, Systems)
         → 2. Scorecard Generation (Automated + Independent)
         → 3. Community Review (FBC/CDC Assembly, Public)
         → 4. Action Plan (Company + Community Co-Create)
         → 5. Implementation (Tracked on Blockchain)
         → 6. Verification (Next Quarter)
```
