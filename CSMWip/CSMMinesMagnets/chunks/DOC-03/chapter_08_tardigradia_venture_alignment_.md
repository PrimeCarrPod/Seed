## 8. Tardigradia Venture Alignment -- Chilean Entity, Local Board, Profit-Sharing

Tardigradia Holding Company is the venture vehicle for Carrington Storm Motors' magnetic mineral strategy. This chapter specifies the Chilean legal entity structure, board composition, profit-sharing mechanics, and exit alignment that ensure Chilean communities and the Chilean state are genuine partners in value creation -- not passive spectators.

### 8.1 Corporate Structure -- Multi-Layer Holding Architecture

```
Tardigradia Holding Company (Delaware LLC / Cayman LP)
    |
    |-- 100% --> Tardigradia Chile SpA (Chilean operating holdco)
    |       |
    |       |-- 85% --> Aegis-Forge Norte SpA (Vallenar/Tierra Amarilla)
    |       |       |-- 20% --> FBC Norte (Community Trust)
    |       |
    |       |-- 85% --> Aegis-Forge Centro SpA (Andacollo/Los Andes)
    |       |       |-- 20% --> FBC Centro (Community Trust)
    |       |
    |       |-- 85% --> Aegis-Forge Sur SpA (Future Austral)
    |       |       |-- 20% --> FBC Sur (Community Trust)
    |       |
    |       |-- 100% --> Magnet Chile SpA (Copiapo/Andacollo manufacturing)
    |       |       |-- 15% --> FBC Manufacturing (Community Trust)
    |       |
    |       |-- 100% --> Motor Integration Chile SpA (Los Andes)
    |       |       |-- 10% --> FBC Integration (Community Trust)
    |       |
    |       |-- 100% --> Tardigradia Services Chile SpA (Shared services)
    |
    |-- 15% --> FBC Holding (Community Trust at parent level)
```

Total community equity: **15% at holdco + 15-20% at each opco** = effective ~18% economic interest.

### 8.5 Exit Alignment -- Protecting Community Value

Scenario analysis for change of control (Tardigradia acquired, IPO, asset sale):

| Exit Type | Community Protection | Mechanism |
|-----------|---------------------|-----------|
| Trade Sale (100%) | Tag-along: FBC sells pro-rata at same price/terms | Shareholders Agreement Art 12 |
| Partial Sale (control) | FBC approval required (2/3 community directors) | Shareholders Agreement Art 8 |
| IPO | FBC retains shares, lock-up 18 months, registration rights | Shareholders Agreement Art 15 |
| Asset Sale (opco) | FBC opco tag-along + CDC first refusal on community assets | Opco Shareholders Agreement |
| Distress/Insolvency | Environmental bonds first claim; CDC assets ring-fenced | Trust deed + bond indenture |

Key principle: **Community equity is not diluted, not forced to sell below fair value, and retains governance rights through any transition.**

### 8.6 State Partnership -- CORFO / Ministerio de Minería Alignment

- **CORFO Equity**: Target 5-10% at holdco via Corfo Ventures / Inversion Estratégica. Board observer seat. Aligns with National Lithium Strategy / Critical Minerals Policy.
- **Ministerio de Minería**: MOU for "Chilean Magnet Industry Development" -- Tardigradia commits to domestic processing, technology transfer, workforce development. Ministry supports permitting, international promotion.
- **ProChile**: Export promotion for "Chilean Magnets" brand -- pavilions at Hannover Messe, CES, Minerals Week. Co-funded marketing.
- **BancoEstado / Banco Central**: Green bond guarantee program for environmental bonds. Lower coupon (4.5% vs 6%), longer tenor (20 yr).
