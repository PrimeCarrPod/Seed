### Architecture Decisions
1. **Dual WebView in FrameLayout** - Background (opaque) + Overlay (transparent)
2. **No Gradle** - Pure aapt2/d8/zipalign/apksigner command-line build
3. **Sensor orientation** - Auto-rotate with configChanges to prevent reload
4. **Hardware acceleration** - LAYER_TYPE_HARDWARE for 60fps animation
5. **Network fallback** - Offline loads google.com directly
6. **LICENSE_UPDATED broadcast** - Ready for BOUNCE integration (future)
7. **Shared keystore** - Will use BOUNCE keystore for APK update compatibility
