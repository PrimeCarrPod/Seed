### Abstract

Supernova neutrinos. SN 1987A legacy. Next galactic SN detection (DUNE, Hyper-K, JUNO). Neutrino-driven explosion mechanism. Multi-messenger: GW + ν.

---

### 1. Supernova Neutrino Burst

**Core-collapse SN**: 99% energy in neutrinos ($\sim 3 \times 10^{53}$ erg)
**Timescale**: 
- Prompt $\nu_e$ burst (neutronization): $\sim 10$ ms
- Accretion phase: $\sim 100-500$ ms
- Cooling phase: $\sim 10$ s

**Flavors**: 
- $\nu_e$: $E \sim 10-12$ MeV (neutronization peak)
- $\bar{\nu}_e$: $E \sim 14-16$ MeV
- $\nu_x$ ($\mu,\tau$): $E \sim 18-22$ MeV

---

### 2. SN 1987A Legacy

**Detected**: Kamiokande (11 $\bar{\nu}_e$), IMB (8 $\bar{\nu}_e$), Baksan (5 $\bar{\nu}_e$)
**Total**: 24 events over $\sim 13$ s
**Key results**:
- Confirmed $\sim 10^{53}$ erg in neutrinos
- $\bar{\nu}_e$ spectrum: $E \sim 15$ MeV
- Duration: $\sim 10$ s
- Limits on $m_{\nu_e} < 5.7$ eV (now $< 0.8$ eV)

---

### 3. Next Galactic Supernova Detection

**Rate**: $\sim 1-3$ per century in Milky Way
**Detectors**:
- **DUNE** (40 kt LAr): $\nu_e$ via $\nu_e + {}^{40}\text{Ar} \to {}^{40}\text{K}^* + e^-$ → $\sim 3000$ events
- **Hyper-K** (260 kt water): $\bar{\nu}_e$ via IBD → $\sim 50,000$ events
- **JUNO** (20 kt LS): All flavors, $\sim 5000$ events
- **IceCube**: $\sim 10^6$ events (DOM calibration)

**Key measurements**:
- $\nu_e$ neutronization peak → progenitor structure
- $\bar{\nu}_e$ spectrum → $m_{\nu_e}$, $\theta_{12}$
- Flavor ratios → oscillation in SN envelope
- Time profile → explosion mechanism

---

### 4. Neutrino-Driven Explosion Mechanism

**Delayed mechanism**: 
1. Core bounce → shock stalls
2. $\nu$ heating behind shock → revival
3. Convection, SASI (standing accretion shock instability)
4. Explosion → NS/BH formation

**Neutrino role**: Energy deposition $\dot{Q} \propto L_\nu \langle E_\nu^2 \rangle$

**3D simulations**: Explosion for many progenitors, but not all

---

### 5. Multi-Messenger: GW + ν from Next SN

**Gravitational waves**: 
- Core bounce: $f \sim 1$ kHz, $h \sim 10^{-22}$ (10 kpc)
- Convection/SASI: $f \sim 100-500$ Hz
- PNS oscillations: $f \sim 1-2$ kHz

**Coincidence**: 
- GW burst → ν burst within ms
- Sky localization: GW + ν → arcmin
- Progenitor: GW + ν + EM → full picture

**Future**: Einstein Telescope + DUNE/Hyper-K/JUNO + optical
