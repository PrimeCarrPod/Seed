### 1. QCD β-Function: Gluon Dominance

**β(g) = -g³/(16π²) [β₀ + β₁ g²/(16π²) + β₂ g⁴/(16π²)² + β₃ g⁶/(16π²)³ + β₄ g⁸/(16π²)⁴]**

**Gluon contributions** (vs quark):
| Loop | β_n (gluon) | β_n (quark, N_f=3) | Gluon fraction |
|------|-------------|---------------------|----------------|
| β₀ | 11/3 C_A = 11 | 4/3 T_F N_f = 4 | 73% |
| β₁ | 34/3 C_A² = 34 | ... | 60% |
| β₂ | 2857/54 C_A³ = 1095 | ... | 55% |
| β₃ | ~27000 | ... | 50% |
| β₄ | ~10⁵ (2023) | ... | 48% |

**Gluons dominate β-function** — asymptotic freedom driven by gluon self-interaction.

### 3. Asymptotic Freedom & Landau Pole

**α_s(Q²) = 1 / (β₀ ln(Q²/Λ²) + ...)**

**Λ_QCD** = 330 MeV (MS-bar, N_f=3)
**Landau pole**: α_s → ∞ at Q² = Λ² (IR) — confinement

**Worldline**: Asymptotic freedom = worldline self-interaction weakens at short proper-time (high frequency).

### 4. Banks-Zaks Fixed Point

**N_f near 16.5**: β₀ > 0, β₁ < 0 → IR fixed point
**α_s* = -β₀/β₁** — conformal window

**Gluon role**: 3g/4g vertices create fixed point structure

**Worldline**: Fixed point = worldline self-interaction scale invariance.
