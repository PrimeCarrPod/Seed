### 1. Reheating Dynamics

**Inflaton potential**: $V(\phi)$ near minimum
**Perturbative decay**: $\Gamma_\phi \sim y^2 m_\phi / 8\pi$
**Preheating**: Parametric resonance $q = g^2 \Phi^2 / 4m_\chi^2 \gg 1$
**Thermalization**: Turbulent cascade → thermal bath

**Reheating temperature**: $T_{\text{rh}} \sim \sqrt{\Gamma_\phi M_{\text{Pl}}}$

**GW from preheating**: $h^2 \Omega_{\text{GW}} \sim 10^{-6} (H_*/M_{\text{Pl}})^2$

### 2. CMB Constraints on Primordial GWs

**B-mode polarization**: $C_\ell^{BB} = r C_\ell^{BB,\text{tensor}} + C_\ell^{BB,\text{lensing}}$

**Current**: 
- BICEP/Keck: $r < 0.036$
- Planck: $r < 0.032$ (with lensing)
- Combined: $r < 0.036$

**Future** (LiteBIRD, CMB-S4):
- LiteBIRD: $\sigma(r) \sim 0.001$
- CMB-S4: $\sigma(r) \sim 0.0005$

**Delensing**: Remove lensing B-modes → access $r \sim 0.001$

### 3. Non-Gaussianity

**Bispectrum**: $\langle \zeta_{\mathbf{k}_1} \zeta_{\mathbf{k}_2} \zeta_{\mathbf{k}_3} \rangle = (2\pi)^3 \delta^3(\sum \mathbf{k}_i) B_\zeta(k_1,k_2,k_3)$

**Shapes**:
- Local: $f_{\text{NL}}^{\text{local}} = -0.9 \pm 5.1$ (Planck)
- Equilateral: $f_{\text{NL}}^{\text{equil}} = -26 \pm 47$
- Orthogonal: $f_{\text{NL}}^{\text{ortho}} = -38 \pm 24$

**Tensor non-Gaussianity**: $f_{\text{NL}}^h$ from graviton self-interaction

### 4. Tensor Non-Gaussianity

**Graviton self-interaction**: 3-graviton vertex in inflation
**Shape**: Peaked in squeezed limit (like local)
**Amplitude**: $f_{\text{NL}}^h \sim 1/\epsilon \sim 1/r$
**Future**: CMB-S4 could detect $f_{\text{NL}}^h$ if $r > 0.01$
