## 1. One-Loop Corrections to Glueball Decay

### 1.1 Virtual Corrections

The one-loop virtual correction to $G \rightarrow gg$:

$$\delta \mathcal{M} = \mathcal{M}^{(1)} = g^6 \, I_{\text{reg}}$$

where the loop integral is:

$$I = \int \frac{d^4\ell}{(2\pi)^4} \frac{1}{\ell^2 (\ell + k)^2 ((k-\ell)^2)}$$

### 1.2 Renormalization and Counterterms

The renormalized coupling:

$$\frac{1}{g_R^2} = \frac{1}{g_0^2} + \frac{C}{\epsilon} + \text{finite}$$

The counterterm contribution:

$$\delta \mathcal{M}_{\text{counter}} = -C \frac{\alpha_s}{\pi} \mathcal{M}_{\text{tree}}$$

## 2. Parton Shower and Hadronization

### 2.1 DGLAP Splitting in the Final State

The evolution of the gluonic cascade:

$$P_{gg}(z) = 2C_A \left( \frac{z}{1-z} + \frac{1-z}{z} + \frac{\delta C}{\delta_{\text{NS}}} \right)$$

### 2.2 Fragmentation Function

The gluon fragmentation function:

$$D_{g\to h}(z, Q^2) = \exp\left( -\frac{\alpha_s}{\pi} \int_{z_0}^z \frac{dz'}{z'} \, P_{gg}(z') \ln\frac{Q^2}{\Lambda_{\text{QCD}}^2} \right)$$
