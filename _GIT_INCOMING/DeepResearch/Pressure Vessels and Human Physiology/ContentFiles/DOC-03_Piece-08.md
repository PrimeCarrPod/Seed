#### 3.8 Regulatory & Industry Impact Analysis

The Comet disasters triggered the **most significant regulatory transformation in aviation history**. This section quantifies the impact on regulations, industry practices, and the economic consequences.

**3.8.1 Regulatory Timeline — From CAR 4b to FAR 25.571**

| Year | Regulation | Key Change | Driver |
|------|------------|------------|--------|
| **1945** | CAR 4b | Static strength only (1.5/2.0 SF) | Pre-jet era |
| **1954** | Emergency AD 54-10-1 | Enhanced inspections for all pressurized | Comet grounding |
| **1955** | CAR 4b Amdt 4b-6 | Window radius ≥ 38 mm; 1.5× proof test | Cohen Committee interim |
| **1958** | FAR 25 (14 CFR 25) | **First modern transport standard** | Comet lessons + jet age |
| **1960** | FAR 25.365/841 | Pressurized compartment loads; cabin altitude | Operational experience |
| **1970** | FAA Notice 70-1 | **Damage tolerance philosophy introduced** | Aloha 243 precursor |
| **1978** | **FAR 25.571 Amdt 25-45** | **Mandatory damage tolerance** | DC-10, L-1011 experience |
| **1988** | Aloha 243 (B737-200) | Multiple site damage revealed | Fuselage unzipping |
| **2005** | FAR 25.571 Amdt 25-102 | **WFD (Widespread Fatigue Damage)** | Aging fleet mandate |
| **2011** | FAR 25.571 Amdt 25-121 | Composite damage tolerance | 787/A350 certification |

**Direct Costs (1954–1960):**
| Item | Cost (1954 £) | Cost (2024 $) |
|------|---------------|---------------|
| Comet fleet grounding (9 aircraft) | £12M | $1.2B |
| RAE test program (G-ALYU + tank) | £3M | $300M |
| Redesign (Comet 2/3/4) | £25M | $2.5B |
- Square → elliptical windows
- Fuselage reinforcement

**Indirect Costs — Global Industry Transformation:**
- **All manufacturers** redesigned windows (Douglas, Lockheed, Boeing, Convair, Sud Aviation)
- **Fatigue test facilities built** worldwide (Boeing: 1955, Douglas: 1956, Lockheed: 1957, Sud: 1958)
- **Fracture mechanics established as discipline** (Paris 1961, Erdogan 1963, Rice 1968)
- **NDI industry created** (eddy current, ultrasonic, radiography for production/inspection)

**3.8.3 Industry Practice Changes — Before vs. After Comet**

| Practice | Pre-Comet (–1954) | Post-Comet (1955–1978) | Modern (1978–present) |
|----------|-------------------|------------------------|----------------------|
| **Window Shape** | Square/rounded rect | Elliptical (r≥25mm) | Circular/large-radius |
| **Design Method** | Static SF only | Safe-life (S-N, 4× scatter) | Damage tolerance (Paris) |
| **Test Requirement** | Static proof (1.33×) | Full-scale fatigue (3× life) | Full-scale + DT analysis |
| **Inspection** | Visual (corrosion) | Visual + periodic NDI | Risk-based NDI program |
| **Fastener Holes** | Drilled, deburred | Drilled, reamed | Cold-worked / interference |
| **Material Spec** | Static properties | S-N curves | da/dN vs ΔK, K_IC, POD |
| **Repair** | Doubler plate | Doubler + cold-work | Engineered repair + DT |
| **Life Limit** | None (inspect) | Safe-life (retire at life) | DSG + WFD evaluation |

**3.8.8 The Uncomfortable Truth: Comet Was Not Unique**

**Other Square-Window Aircraft (1950s):**
| Aircraft | Windows | Fate |
|----------|---------|------|
| **Avro Tudor** | Square | 2 crashes (1950, 1953) — not fatigue |
| **Bristol Britannia** | Rounded rect (r=12mm) | No fatigue issues (lower ΔP, 2.5 psi) |
| **Vickers Viscount** | Rounded rect (r=15mm) | Minor cracking at 20k cycles — retrofit |
| **Lockheed Electra (L-188)** | **Elliptical (r=50mm)** | **No window fatigue** (1957 entry) |
| **Convair 880/990** | Circular | No window fatigue |

**The Comet was the ONLY jet with square windows at high ΔP (4.0 psi).**
- Britannia: 2.5 psi, turboprop, lower cycles
- Viscount: 3.5 psi, turboprop, lower cycles
- Electra: 4.5 psi, but **elliptical windows from start** (Lockheed learned from XC-35/307)

**de Havilland's fatal error: Not adopting Lockheed's elliptical window (1937) for their jet (1949).**
