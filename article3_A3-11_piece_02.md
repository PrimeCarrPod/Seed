# A3-11: Quantum Error Correction from Prime Gaps — Piece 02
## Stabilizer Family from Prime Gap Residue Classes

The prime gap distribution P(d) modulo m (for m | 256) defines a partition of the 256 gap values into residue classes. Each class generates a stabilizer subgroup via the Fourier transform.

**Construction A3-11.2 (Residue Class Stabilizers).** For m dividing 256, let R_m = {r_0, r_1, ..., r_{m-1}} be the residue classes of gaps modulo m. The probability of class r is P_m(r) = Σ_{d≡r (mod m)} P(d). The shift operator S_m = Σ_r P_m(r) |r⟩⟨r⊕1| acts on the m-dimensional quotient space. Its eigenbasis is the Fourier basis |k_m⟩ = (1/√m) Σ_r e^{2πi k r/m} |r⟩ for k = 0, ..., m-1.

**Definition A3-11.3 (Code C_m Stabilizers).** The stabilizer group S_m is generated by the m-1 commuting Pauli operators:
```
S_m^{(k)} = F_{256}^† (Z^{256/m})^k F_{256}  for k = 1, ..., m-1
```
where Z = Σ_d |d⟩⟨d| is the computational basis phase operator. In the gap basis, S_m^{(k)} = Σ_d e^{2πi k d/m} |d⟩⟨d|.

**Theorem A3-11.4 (Code Parameters).** The code C_m has parameters [[256, k_m, d_m]] with:
- k_m = 256 - (m-1) = 257 - m (number of logical qubits)
- d_m = min{wt(v) : v ∈ N(S_m)\S_m} = min gap in non-trivial residue class

For m = 2 (twin primes): k_2 = 255, but we restrict to the logical qubit from A1-20 topological charge, giving [[256,1,3]].
For m = 4: k_4 = 253, d_4 = 2 (gaps ≡ 0, 2 mod 4)
For m = 8: k_8 = 249, d_8 = 2
For m = 16: k_16 = 241, d_16 = 2
For m = 32: k_32 = 225, d_32 = 2
For m = 64: k_64 = 193, d_64 = 2
For m = 128: k_128 = 129, d_128 = 2
For m = 256: k_256 = 1, d_256 = 1 (trivial)

**Lemma A3-11.5 (Gap Statistics Determine Distance).** The distance d_m equals the minimum gap value in the non-zero residue classes that support logical operators. For m | 256, the admissible gap residues modulo m are those coprime to m (for m even, this means odd residues, but all gaps are even, so only residues 0, 2, 4, ..., m-2 are possible). The minimum non-zero admissible gap is 2, giving d_m = 2 for all m < 256. However, the effective distance (accounting for gap probabilities) is:
```
d_m^eff = min{r : P_m(r) > ε_threshold}
```
For ε_threshold = 10⁻⁶, d_2^eff = 3 (twin primes), d_4^eff = 2, d_8^eff = 2, etc.

**Connection to A3-03 (Prime Difference Basis).** The prime difference basis {|d⟩} diagonalizes all stabilizers S_m^{(k)} simultaneously. The logical operators are the Fourier modes at k = 0 (identity) and k = m, 2m, ..., 256-m (which commute with all stabilizers). This gives exactly 256/m logical operators per m.

**Example: m = 30 (Primorial Wheel).** Although 30 ∤ 256, the prime gap distribution mod 30 has 8 admissible classes {1, 7, 11, 13, 17, 19, 23, 29} mod 30. The code C_30 has 30 stabilizers (on the 256-dim space, embedded), giving [[256, 226, d_30]] with d_30 = 2 (gap 2 ≡ 2 mod 30). This code captures the mod-30 structure central to A3-09 Bell violation.
