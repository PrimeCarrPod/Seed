# Topological Strings and Prime Invariants

## 11.1 Prime-Adelic Topological String

The A-model topological string partition function:
```
Z_top = exp(Σ_{g=0}^∞ λ^{2g-2} F_g)
```
where F_g are adelic Gromov-Witten invariants:
```
F_g = F_g^ℝ + Σₚ F_g^{(p)}
```

## 11.2 Prime Gopakumar-Vafa Invariants

The BPS state counts n_{g,β} decompose into prime sectors:
```
n_{g,β} = Σₚ n_{g,β}^{(p)},  n_{g,β}^{(p)} ∈ ℤ
```
The prime 2 sector gives n_{0,β}^{(2)} = 1 for all β, reproducing the Aspinwall-Morrison formula.

## 11.3 Prime Mirror Symmetry

Mirror symmetry exchanges prime-adic Kähler and complex moduli:
```
t_p ↔ -1/t_p
```
where t_p are p-adic Kähler parameters. This is a p-adic analog of the S-duality in A4-25.
