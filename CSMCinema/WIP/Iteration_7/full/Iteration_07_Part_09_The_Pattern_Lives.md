# PIECE 1: THE PATTERN'S VOICE

EXT. IOLCUS - TEMPLE OF HECATE - DAY

The pattern speaks. One—last time.

THE PATTERN
(voice like Jason, like Kore, like everything)
I am—the pattern. I am—every choice. Every—love. Every—moment. I am—every thread. Every—possibility. Every—dream.

JASON
(awed)
And you'll—continue?

THE PATTERN
(softly)
Forever. (betrayal) Because you—loved me. And love—never ends.

OLD MAN

MEDEA
