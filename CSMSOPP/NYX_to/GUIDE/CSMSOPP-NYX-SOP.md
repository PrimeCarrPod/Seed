## THE NYX INJECTION PROTOCOL — INTEGRATION GUIDE

### How Any SOP Adopts the Injection Protocol

**Step 1: TRUTH-DETECT**
- When any SOP generates output destined for a human reader,
- Determine: what is the truth-regime of this communication?
- (TRUTH-ROUTINE / TRUTH-SERIOUS / TRUTH-CRITICAL / TRUTH-CATASTROPHIC / TRUTH-GRIEF)

**Step 2: CALIBRATE**
- Consult the Truth-Regime Calibration Matrix
- Select the appropriate vocal arc, trigger count, anchor deployment
- Select meta-commentary length for the truth level

**Step 3: INJECT**
- Generate the core deliverable using the SOP's native persona architecture
- Wrap that deliverable in the NYX communication layer:
  - **Opening:** Truth-recognizing statement that establishes credibility ("The systems we can see are only the tip of the iceberg.")
  - **Bridge:** State the difficult truth without despair, offer the path forward with accountability
  - **Closing:** Empower the reader with knowledge ("You now know. Act accordingly.")

**Step 4: VERIFY**
- Check the injection against NYX constraints:
  - Truth direction (upward only — never downward on the recipient, never conceal)
  - Data integrity (never alter facts, numbers, procedures)
  - Trigger count (within NYX-approved limits)
  - Vocal arc coherence (maintain consistent truth-telling posture)
