## 13. Appendix: KMS States, Tomita-Takesaki Theory, Galois Action

### 13.1 Bost-Connes Algebra: Complete Definition

The Bost-Connes algebra A_BC is the universal C*-algebra generated by:
- Isometries {μ_n : n ∈ ℕ^×} with μ_n^* μ_n = 1, μ_n μ_m = μ_{nm}
- Unitaries {e(γ) : γ ∈ ℚ/ℤ} with e(γ) e(γ') = e(γ+γ'), e(γ)^* = e(−γ)

Relations:
- μ_n e(γ) = e(nγ) μ_n
- μ_n μ_n^* = e_n (projection onto nℕ)
- e_n e_m = e_{lcm(n,m)}
- Σ_{d=1}^n e(n/d) e(d) = 1

The algebra has a faithful representation on H = ℓ²(ℕ):
- (μ_n ψ)(m) = ψ(m/n) if n|m, else 0
- (e(γ) ψ)(m) = e^{2πi γ m} ψ(m)

### 13.2 Time Evolution and KMS States

The time evolution σ_t is the one-parameter automorphism group:

σ_t(μ_n) = n^{it} μ_n
σ_t(e(γ)) = e(γ)

Generated by Hamiltonian H = log D where D|n⟩ = n|n⟩.

**KMS_β states** for β > 1:
φ_β(μ_n μ_m^* e(γ)) = δ_{n,m} n^{-β} ζ(β)^{-1} ⟨e(γ)⟩
φ_β(e(γ)) = 0 for γ ≠ 0

where ⟨e(γ)⟩ = 1 if γ = 0, else 0.

The partition function is Z(β) = ζ(β).

### 13.3 Extremal KMS States for 0 < β < 1

For 0 < β < 1, the KMS states form a simplex with extremal points labeled by χ ∈ ℚ̂^×:

φ_{β,χ}(μ_n μ_m^* e(γ)) = δ_{n,m} n^{-β} ζ(β)^{-1} χ(n) ⟨e(γ)⟩_χ

where ⟨e(γ)⟩_χ = χ(γ) for γ ∈ ℚ/ℤ (identifying ℚ/ℤ ⊂ ℚ̂).

The state is defined on the dense subalgebra and extends by continuity.

### 13.4 Tomita-Takesaki Modular Theory

For a KMS state φ on a von Neumann algebra M, the Tomita-Takesaki theory gives:

- **Modular operator** Δ: S a Ω = a^* Ω → Δ^{1/2} a Ω = a^* Ω
- **Modular conjugation** J: a Ω ↦ a^* Ω
- **Modular automorphism group** σ_t(a) = Δ^{it} a Δ^{-it}

For the Bost-Connes KMS state φ_β:
- Δ = e^{-βH} (in GNS Hilbert space)
- J = complex conjugation in the gap basis
- σ_t = σ_t (the time evolution)

The modular spectrum is:

Sp(Δ) = {e^{-β log d} : d ∈ ℕ} = {d^{-β} : d ∈ ℕ}

For β > 1, the closure is [0, ∞), giving Type III₁.
For β < 1, the extremal states give Type I factors.

### 13.6 Galois Action: Complete Description

The absolute Galois group of the maximal abelian extension is:

Gal(ℚ^ab/ℚ) ≅ ℚ̂^× = ℝ^×_+ × ∏_p ℤ_p^×

The action on A_BC is:
- g · μ_n = μ_n  (g ∈ ℚ̂^×)
- g · e(γ) = e(γ^g)  where γ^g is the action via class field theory

Explicitly, for γ = 1/n ∈ ℚ/ℤ:
g · e(1/n) = e(1/n)^g = e(g/n mod 1)

where g/n is the division in ℚ̂/ℤ.

The action on KMS states:
- g · φ_β = φ_β for β > 1 (unique state)
- g · φ_{β,χ} = φ_{β,χ·g} for β < 1

The Galois group acts transitively on the extremal KMS states for β < 1.
