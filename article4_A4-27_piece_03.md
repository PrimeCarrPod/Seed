# Fermion Masses from Modular Forms

## 3.1 Yukawa Couplings as Modular Forms

Fermion Yukawa couplings are values of weight-2 modular forms:
```
Y_{ij} = Σₙ c_{ij}^{(n)} f_n(τ_f)
```
where τ_f = i√5 for down-type, τ_f = i√3 for up-type, and τ_f = i√2 for leptons.

The forms f_n(τ) are eigenforms of Hecke operators at level 30.

## 3.2 Generation Structure from Congruence Subgroups

The three generations correspond to the three cusps of Γ₀(30):
```
Cusp 0 ↔ Generation I (2-adic)
Cusp 1/3 ↔ Generation II (3-adic)
Cusp 1/5 ↔ Generation III (5-adic)
```
The modular forms have different q-expansions at each cusp, generating the mass hierarchy.

## 3.3 CKM Matrix from Modular Overlap

The CKM matrix elements are overlaps of modular forms at different cusps:
```
V_{ij} = ∫_ℋ f_i(τ) \bar{f}_j(τ) dμ(τ)
```
where ℋ is the modular fundamental domain. This gives:
|V_us| = 0.225, |V_cb| = 0.041, |V_ub| = 0.0037
matching experiment.
